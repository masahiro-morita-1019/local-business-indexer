# ターゲット業種ガイド

「どの業種を `--category` に指定すると AI 製サイトを売りやすいか」の整理。

> 📌 これはツールが自動で絞り込む対象ではなく、**運用者(あなた)が CLI 実行時に指定する業種を選ぶための判断材料**。実行例: `pnpm indexer discover --area "所沢市" --category "外壁塗装"`

---

## 選定基準

AI製の汎用ランディングページが「成約に直結する売上」になりやすい業種は、以下の3条件を満たすもの:

1. **1案件あたりの単価が大きい**(数万円〜数百万円)
2. **HP保有率が低い、または既存HPの質が低い**(ネット弱者の比率が高い)
3. **顧客の購買行動が「ググって電話」**(Web経由の流入が直接成約に直結する)

逆に、ホットペッパー/食べログなどのポータルが流入を支配している業種は単独HPの効果が薄く、AIサイト売り込みの相性は悪い。

---

## Tier 別 推奨業種(2026-05-21 時点)

### 🟢 Tier S — 最有力候補(まず狙うべき)

単価高 × HP保有率低 × Web経由直接成約 の三拍子。

| 業種 | CLI category 例 | 単価感 | HP保有率(肌感) | 営業相性 |
|---|---|---|---|---|
| 外壁塗装 | `外壁塗装` | 60〜200万円/件 | 中(古いHPが多い) | ◎ |
| リフォーム | `リフォーム` | 50〜500万円/件 | 中 | ◎ |
| エアコンクリーニング | `エアコンクリーニング` | 1〜3万円/件(リピート前提) | 低 | ◎ |
| 害虫駆除 | `害虫駆除` | 3〜20万円/件 | 低 | ◎ |
| 不用品回収 | `不用品回収` | 1〜15万円/件 | 低 | ◎ |
| ハウスクリーニング | `ハウスクリーニング` | 2〜10万円/件 | 低〜中 | ◎ |
| 給湯器交換 | `給湯器交換` | 15〜50万円/件 | 中 | ○ |
| 鍵屋 | `鍵屋` / `鍵交換` | 1〜10万円/件 | 中 | ○ |

**狙い方**:
- `--area` は **首都圏郊外〜地方中核都市**(個人事業主比率が高い)
- 一回の `discover` で 60件取って、`OutreachPriority=高` で 10〜20件出れば及第点

### 🟡 Tier A — 月額継続収入向き(Phase 6 レビュー対策と相性◎)

レビュー対策の継続収入(月3-8万円 × 10社)を組み込みやすい。サイト制作スポット + レビュー対策月額 のパッケージで売る。

| 業種 | CLI category 例 | 備考 |
|---|---|---|
| 整体院 / 整骨院 | `整体院` / `整骨院` | レビュー件数の差が来店数に直結 |
| 接骨院 | `接骨院` | 同上 |
| 歯科医院 | `歯科医院` | 法律上の広告制限あり(あおり禁止等)、AI生成文面で注意 |
| 士業事務所(税理士/司法書士/行政書士) | `税理士` / `司法書士` / `行政書士` | 信頼性訴求が刺さる |
| 動物病院 | `動物病院` | レビュー効果大 |

### 🔵 Tier B — 単価最高だが要注意

単価は最大級だが、AIの汎用テンプレでは「事例写真」や「施工実績」が薄いと購買決定要因にならない。

| 業種 | CLI category 例 | 注意点 |
|---|---|---|
| **工務店** | `工務店` | 注文住宅は知人紹介・モデルハウス主導。MVP動作確認には使えるが、本命の営業対象としては優先度低 |
| 設備屋(配管/電気工事) | `配管工事` / `電気工事` | 法人取引が多く、B2C向け汎用LPでは弱い |
| 解体業 | `解体業` | 単価高だが受注源が業者経由のことが多い |
| 内装工事 | `内装工事` | 法人受注が主流 |

### ⚪ Tier C — 単独HPは不要に近い

ポータル支配が強く、独自HPの単独効果が薄い。

| 業種 | 理由 |
|---|---|
| 飲食店 | 食べログ/ホットペッパー/Googleマップ単独で完結 |
| 美容院 / 理容室 | ホットペッパービューティーが支配 |
| 居酒屋/カフェ | 予約はぐるなび/食べログ経由が主流 |

---

## 進め方の推奨(現状の MVP に対する)

- **MVP動作確認**: 引き続き `工務店` で OK(既にデータが蓄積されている)
- **最初の有償案件取り**: `外壁塗装` または `リフォーム` で営業候補を集める
  ```bash
  pnpm indexer discover --area "所沢市" --category "外壁塗装" --limit 60
  pnpm indexer discover --area "町田市" --category "リフォーム" --limit 60
  ```
- **慣れたら横展開**: Tier S を順に試して、自分の動き方と合う業種を1〜2に絞る
- **継続収入を組む段階**: Tier A の業種に向けて Phase 6(レビュー対策)を提供する

## カテゴリ追加・変更時のメモ

ツール側はカテゴリを **そのまま Places API のテキスト検索クエリ** に渡すだけなので、`--category` に新しい業種文字列を指定すれば即試せる(コード変更不要)。

このドキュメントは「あなたが業種を選ぶための知識」であり、ツールの自動分類とは独立した運用ガイド。
